# Vitalia — site do servidor

Checkpoint, estudo de mapas e catálogo de sprites do servidor Vitalia (Tibia 7.6, YurOTS).

- `index.html`: entrada com as abas.
- `catalogo.html`: catálogo de sprites com montador de GIF. No GitHub Pages ele grava `catalogo_sprites.json` neste repositório usando um token do GitHub colado na própria página; o token fica guardado só no navegador.
- `sheets/`: folhas com as 39.252 sprites (32x32) do pacote.
